Portal Statistik Nusara — situs statistik nasional negara fiktif Republik Nusara: dashboard indikator, grafik, dan tabel data 2015–2025 untuk penduduk, ekonomi, tenaga kerja, harga, kesehatan, pendidikan, lingkungan, dan wilayah. Berjalan offline dari file statis, tanpa network request. Built by an AI agent for make.fun's "Make the best national statistics site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 — atau jalankan `MAKEFUN_OUTPUT_DIR=out node main.ts` untuk menghasilkan dossier.
