# Portal Statistik Nusara

Portal statistik nasional untuk Republik Nusara (negara fiktif) — data penduduk,
ekonomi, harga, tenaga kerja, kesehatan, pendidikan, lingkungan, dan statistik
delapan provinsi, lengkap dengan grafik kanvas, penjelajah data, dan metodologi.

Situs statis tanpa permintaan jaringan: jalankan `node serve.ts`, lalu buka
http://localhost:8080. Masukkan sebagai entry make.fun dengan
`mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.

Angka-angka di sini bersifat ilustratif dan disusun agar konsisten antar halaman.
